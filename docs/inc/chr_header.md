## Constants
**Normal**
| Name | Description |
| --- | --- |
| `CHR_BS` | Backspace character |
| `CHR_LF` | Line feed character |
| `CHR_CR` | Carriage return character |
| `CHR_SP` | Space character |
| `CHR_QT` | Quote character |
| `CHR_HS` | Hash character |
| `CHR_DL` | Dollar character |
| `CHR_AP` | Apostrophe character |
| `CHR_HY` | Hyphen character |
| `CHR_PRD` | Period character |
| `CHR_SL` | Slash character |
| `CHR_BSL` | Backslash character |
| `CHR_COL` | Colon character |
| `CHR_US` | Underscore character |
| `CHR_EQ` | Equal character |
| `CHR_LT` | Less than character |
| `CHR_GT` | Greater than character |
| `CHR_ZERO` | Zero character |

**Else**
| `CHR_UC_A` | Uppercase a character |
| `CHR_UC_Z` | Uppercase z character |
| `CHR_LC_A` | Lowercase a character |
| `CHR_LC_Z` | Lowercase z character |
| `CHR_LC_N` | Lowercase n character |
| `CHR_CASE_MASK` | Case mask, change uppercase to lowercase or lowercase to uppercase |
