## Constants
| Name | Description |
| --- | --- |
| `APM_CMD_CHK_VER` | Check current version |
| `APM_CMD_CONN_REAL` | Connect to real mode |
| `APM_CMD_STATE` | Set power state |
| `APM_CMD_ENABLE` | Enable, require version greater than 1.1 |
| `APM_ID_SYS` | System ID |
| `APM_DEV_ALL` | All device |
| `APM_STATE_OFF` | Power off |
| `APM_OLD_VER` | Old version for needless enable command |
| `BIOS_SYS` | BIOS system interrupt number |
