# Documentation
Every files follow the documentation rules, Examples:
- `boot/boot.s` - `docs/boot/boot.md`
- `kernel/args/args.s` - `docs/kernel/args/args.md`

---

## Directory Structure
- boot/ - Boot
- cmd/ - Commands
- fayfs/ - File system for Fayos
- include/ - Constants only
- kernel/ - Kernel for Fayos
- lib/ - Library
- tools/ - Misc
